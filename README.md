# Случайный путь (Random Walk Animation)

**Автор:** Лопухов Даниил Русланович

**Дисциплина:** Практикум по программированию

## Описание проекта
Программа визуализирует случайный путь точки. На каждой итерации точка смещается на заданный шаг. Реализована интерактивная настройка параметров пути с помощью графических слайдеров (величина шага, приоритетное направление и сила притяжения).

## Функциональные возможности
### Основной функционал
- Отрисовка случайного блуждания точки из центра экрана
- Зацикленная плавная анимация
- Автоматический возврат точки в центр при выходе за границы
### Дополнительный функционал
- Интерактивная регулировка величины шага
- Настройка приоритетного направления движения (в градусах)
- Изменение "силы притяжения" к выбранному направлению

## Требования к системе
- **Python:** 3.9 или выше
- **Операционная система:** macOS / Windows / Linux
- **Библиотеки:** `tkinter` (встроенная), `math`, `random`
