## Описание проекта
Программа представляет собой графическое приложение с использованием библиотеки `tkinter`, которое в реальном времени визуализирует математическую модель «случайного блуждания» (Random Walk) точки на плоскости. На каждой итерации главного цикла точка смещается из центра экрана на заданный шаг в направлении, рассчитываемом путем линейной интерполяции случайного вектора и вектора приоритетного направления. Пользователю предоставлена возможность интерактивного управления параметрами движения прямо во время работы анимации с помощью графических слайдеров.

---

## Функциональные возможности

### Основной функционал
- **Генерация случайного пути:** непрерывная отрисовка траектории движения точки белым цветом на контрастном черном холсте.
- **Старт из центра координат:** начальное положение точки автоматически вычисляется как геометрический центр окна ($x = 400$, $y = 300$).
- **Контроль границ экрана:** автоматический возврат точки в центр экрана при выходе за пределы рабочей области холста.
- **Плавная анимация:** использование неблокирующего цикла событий `root.after()` с обновлением кадра каждые $20$ мс (около $50$ кадров в секунду).

### Дополнительный функционал
- **Регулировка шага:** интерактивное изменение длины одного шага точки в диапазоне от $1$ до $30$ пикселей.
- **Приоритетное направление:** выбор угла вектора притяжения от $0^\circ$ до $360^\circ$ с помощью ползунка.
- **Настройка «силы притяжения»:** плавная регулировка коэффициента влияния приоритетного направления от $0.0$ (абсолютно случайное блуждание) до $1.0$ (строго направленное движение по заданному углу) с шагом $0.01$.

## Требования к системе
- **Python:** версия 3.9 или выше (проект протестирован на Python 3.12)
- **Операционная система:** macOS / Windows / Linux
- **Библиотеки:**
  - `tkinter` — стандартная встроенная графическая библиотека Python (для отрисовки окна, холста и слайдеров)
  - `math` — встроенный модуль для тригонометрических расчетов ($\cos$, $\sin$, нормализация вектора через `hypot`)
  - `random` — встроенный модуль для генерации псевдослучайного угла направления

## Установка и запуск

Ниже приведена подробная пошаговая инструкция, позволяющая развернуть и запустить проект на любом компьютере.

### 1. Клонирование репозитория
Откройте терминал (на macOS/Linux) или командную строку / PowerShell (на Windows), перейдите в папку, где вы хотите разместить проект, и выполните команды:

```bash
git clone https://github.com/Depshen/3.1_Simple_Animation.git
cd 3.1_Simple_Animation
```

### 2. Создание и активация виртуального окружения
Проект использует изолированное виртуальное окружение `venv`.

**Для macOS и Linux:**
```bash
python3 -m venv venv
source venv/bin/activate
```

**Для Windows:**
```bash
python -m venv venv
venv\Scripts\activate
```
*(После успешной активации в начале командной строки терминала появится префикс `(venv)`).*

### 3. Проверка зависимостей
Программа использует исключительно встроенные в стандартную библиотеку Python модули (`tkinter`, `math`, `random`). В соответствии с техническими требованиями к проекту, в файле `requirements.txt` указана базовая платформа `Python`, поэтому установка сторонних пакетов через `pip` не требуется.

> **Примечание для пользователей macOS и Linux:** если при запуске возникнет ошибка `ModuleNotFoundError: No module named '_tkinter'`, установите пакет поддержки графического интерфейса для вашей версии Python (например, на macOS через Homebrew: `brew install python-tk`).

### 4. Запуск программы
Находясь в корневой папке проекта `3.1_Simple_Animation` с активированным виртуальным окружением, запустите точку входа:

**На macOS / Linux:**
```bash
python3 main.py
```

**На Windows:**
```bash
python main.py
```

### 5. Управление в программе
После запуска откроется графическое окно размером $800 \times 600$ пикселей. В нижней части окна расположена панель с тремя интерактивными слайдерами:
- **«Величина шага»** — передвигайте ползунок вправо, чтобы увеличить длину штриха на каждом шаге, или влево — для мелкого детального движения.
- **«Направление (градусы)»** — задайте угол (от $0^\circ$ до $360^\circ$), в сторону которого будет смещаться точка ($0^\circ$ — вправо, $90^\circ$ — вниз, $180^\circ$ — влево, $270^\circ$ — вверх).
- **«Сила притяжения (0-1)»** — установите значение `0.00` для полностью хаотичного движения, промежуточное значение (например, `0.25`) для дрейфа в выбранную сторону, или `1.00` для движения строго по прямой линии.
- **Завершение работы** — нажмите на стандартную кнопку закрытия окна (крестик в углу окна).

## Структура проекта

```text
3.1_Simple_Animation/
├── .gitignore          # Исключения системы контроля версий (__pycache__, *.pyc, .DS_Store)
├── README.md           # Визитная карточка проекта, описание и инструкция по запуску
├── requirements.txt    # Зависимости проекта (базовое окружение Python / tkinter)
├── main.py             # Точка входа в приложение
├── venv/               # Виртуальное окружение Python (включено в репозиторий для проверки)
└── src/                # Пакет с исходным кодом программы
    ├── __init__.py     # Инициализатор пакета src
    └── app.py          # Модуль с классом App (GUI, математическая логика и анимация)
```

**Назначение основных модулей и обоснование структуры:**
- `main.py` — отвечает исключительно за инициализацию корневого окна `tk.Tk()`, создание экземпляра приложения и запуск главного цикла обработки событий `root.mainloop()`.
- `src/app.py` — содержит класс `App`, который инкапсулирует создание холста (`Canvas`), элементов управления (`Scale`) и метод математического расчета следующего шага `_walk_step()`.
- **Обоснование структуры:** так как проект использует один компактный математический алгоритм и три элемента управления, объединение логики отрисовки и расчета внутри единого класса `App` в пакете `src/` позволяет избежать избыточной фрагментации кода, сохраняя при этом строгую модульность и полное соответствие стандартам PEP 8 и PEP 257.

## Пример использования

### 1. Запуск из терминала
```bash
cd 3.1_Simple_Animation
source venv/bin/activate
python3 main.py
```

### 2. Сценарии экспериментов с моделью
1. **Классическое броуновское движение:**
   - Установите **Величину шага** = `5`, **Силу притяжения** = `0.00`.
   - *Результат:* точка будет хаотично блуждать вокруг центра экрана, образуя плотное «облако» траекторий.
2. **Направленный дрейф (эффект ветра):**
   - Установите **Величину шага** = `10`, **Направление** = `45` (движение в правый нижний угол), **Силу притяжения** = `0.30`.
   - *Результат:* траектория сохранит случайные изгибы, но точка будет стабильно смещаться по диагонали вправо-вниз до границы экрана, после чего вернется в центр и продолжит цикл.
